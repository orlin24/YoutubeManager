Kebijakan Privasi - AI YouTube Manager

Terakhir diperbarui: 12 Agustus 2026

Data yang kami proses

Aplikasi ini adalah alat pribadi (self-hosted) untuk mengelola channel YouTube Anda. Setelah Anda memberikan izin melalui Google OAuth, aplikasi mengakses data channel YouTube Anda melalui YouTube Data API dan YouTube Analytics API, termasuk: daftar video, statistik penayangan, subscriber, komentar, dan data analitik lainnya.

Token & kredensial

Token akses OAuth Google Anda disimpan terenkripsi di server tempat aplikasi berjalan (perangkat pribadi Anda). Token digunakan hanya untuk memanggil API YouTube atas nama Anda dan tidak dibagikan kepada pihak ketiga mana pun.

Penyimpanan data

Data channel (video, statistik, komentar, dan hasil analisis AI) disimpan di database aplikasi di server pribadi Anda. Tidak ada data yang dijual, disewakan, atau dibagikan kepada pihak ketiga.

Layanan AI

Aplikasi dapat mengirim data performa channel Anda ke penyedia layanan AI (sesuai konfigurasi Anda, misalnya OpenAI-compatible API) untuk menghasilkan rekomendasi konten dan laporan.

Hak Anda

Anda dapat mencabut akses aplikasi ke akun Google Anda kapan saja melalui halaman izin akun Google (myaccount.google.com) atau dengan menghapus koneksi di aplikasi. Anda dapat menghapus seluruh data dengan menghapus file database aplikasi.
