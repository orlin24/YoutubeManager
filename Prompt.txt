# 6. GOOGLE / YOUTUBE OAUTH

Implementasikan Google OAuth 2.0.

Jangan meminta user memasukkan password YouTube.

Flow:

```text
Dashboard
   ↓
Connect YouTube
   ↓
Google OAuth
   ↓
Permission
   ↓
Callback
   ↓
Get channel
   ↓
Save encrypted token
   ↓
Channel appears in dashboard
```

Gunakan OAuth scope seminimal mungkin sesuai kebutuhan.

Untuk fitur yang membutuhkan perubahan data YouTube, gunakan OAuth authorization.

Refresh token harus disimpan secara aman dan terenkripsi.

Buat endpoint:

```text
GET /api/auth/google
GET /api/auth/google/callback
POST /api/youtube/disconnect
GET /api/youtube/accounts
```

Jika OAuth belum dikonfigurasi, tampilkan error yang jelas:

```text
Google OAuth is not configured.
Please configure GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET.
```

Jangan crash.
